## kratos学习仓库
### 仓库简介
这是一个用于学习go-kratos框架的仓库，其中有官方demo、examples以及我自己编写的一些项目
### 仓库内容
目前，这个仓库有如下项目：
* [kratos_examples](./kratos_examples)：kratos官方实例。内含多种kratos使用场景
* [beer-shop-main](./beer-shop-main)：kratos官方项目。相比与kratos_examples,它更像是一个综合性的大型项目
* [kratos-shop](./kratos-shop)：不同于kratos官方项目beer-shop-main，该项目一步一步模仿[Go-kratos 框架商城微服务实战之用户服务](https://learnku.com/articles/64942)，并有一些小修改（比如有的函数已废弃，我将其进行了更新）
* [real_world](./real_world)：来自`github`的star数极高的一个经典demo范例[real-world](https://github.com/gothinkster/realworld)。这是它的go-kratos后端实现
* student：这个基本上没什么用，未来考虑从仓库中删除
* [video_web](./video_web)：这个项目将作为我的毕业设计。它涵盖了前、后端，使用了多种技术，如使用kratos搭建微服务框架；使用MySQL、mongoDB、Redis搭建一套存储系统；等等等等。由于该项目比较庞大，我为其专门设置了一个[仓库](https://github.com/EmbraceTheLight/VideoWeb-Refactored-version)，在这个仓库里会有更具体的介绍
